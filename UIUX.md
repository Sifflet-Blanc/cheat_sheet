# UI/UX

Only one button per primary page 

And in general 1 primary button per page (ex: return or cancel)

Input text (un label, ...)

Checkbox (only for multiple selection)
radio (only for one selection)

Dropdown (select) (when there is any option)

Tooltip (small aid message)

Modale (small windows)
- confirm 
- important information
- critic action

Loader
- skeleton 
- loader

state of a component
- default
- hover
- disable
- active
- loading


3 fundamental rules:
- Visual order
  The user need to understand
  - what to do 
  - ... 
- White space 
  Don't be afraid of white space
- Reduct cognitive charge

Common error:
- Many buttons to the same level
- error message don't understandable
- don't do any feedback (every action needs to do something visual)
- not any progress bar (ex e-commerce, ...)
- Don't create something too different in ux (because the user won't know how to use it)
- Don't have any confirmation on critic action
- Forget mobile interface (60–70% of the web market is on smartphones)


Accessibility :
- Contrast 
  - core text minimum ratio 4.5 : 1
  - Title text minimum ratio :1
- Title structure 
  - h1 principal title
  - h2 section title 
  - h3 sub-section title
- don't transmit information only with color (not only the icon either)
