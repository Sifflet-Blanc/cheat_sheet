# SOLID
- **S**ingle responsability principle (une classe/fonction, une fonction)
- **O**pen-closed principle (le code ne change pas)
- **L**iskov substitution principle (element remplacable)
- **I**nterface segregation principle (avoir des impl qui utilisent toutes les methodes definies dans les interfaces)
- **D**ependancy inversion principle (depend des interfaces pas des impl)
